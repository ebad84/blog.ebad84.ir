# ebad84 / log (static)

بلاگ استاتیک خام: فقط HTML و CSS و JS. بک‌اند نداره، API گیت‌هاب نداره، و هر چیزی که نشون می‌ده رو از همین سایت می‌خونه (از آدرسی که بازش کردی).

## اجرا

بدون ساختن چیزی؛ پوشه رو هر جا که فایل استاتیک سرو می‌کنه بذار (nginx، GitHub Pages، Cloudflare Pages، ...). برای تست محلی:

    python -m http.server 8000     # بعد: http://localhost:8000

(با دابل‌کلیک روی فایل کار نمی‌کنه چون مرورگر `fetch` رو روی `file://` بلاک می‌کنه.)

## آدرس‌ها

    /                  لیست پست‌ها
    /#my-post          پست  → posts/my-post.md  (یا posts/my-post/index.md)
    /#tag/esp32        لیست فیلتر‌شده با تگ
    /editor.html       صفحه‌ی نوشتن

آدرس پست‌ها با `#` هست تا روی هر هاستی بدون تنظیم سرور کار کنه.

## اضافه کردن پست

1. توی `/editor.html` بنویس، بعد **Download .md** یا **Copy** بزن.
2. فایل رو بذار توی `posts/` با همون اسمی که صفحه نشون می‌ده (`posts/my-post.md`).
3. اسمش رو به لیست `posts/posts.json` اضافه کن:

        ["hello-world.md", "my-post.md", "esp32-i2s/index.md"]

   لیست لازمه چون سایت استاتیک نمی‌تونه محتوای پوشه رو لیست کنه. اگه فایل رو داخل لیست نذاری، لینک مستقیمش (`/#my-post`) باز هم کار می‌کنه، فقط توی صفحه‌ی اصلی نمی‌آد.

پستی که فایل یا عکس داره: `posts/my-post/index.md` بساز و فایل‌ها رو کنارش بذار (`posts/my-post/files/x.zip`)، بعد توی متن با آدرس نسبی لینک کن: `[دانلود](files/x.zip)` یا `![](img/a.png)`. توی لیست می‌نویسی `"my-post/index.md"`.

## فرانت‌متر (بالای هر `.md`)

    ---
    title: عنوان پست
    date: 2026-11-08        # برای مرتب‌سازی
    tags: [esp32, audio]
    dir: auto               # auto | rtl | ltr
    draft: true             # از لیست مخفی می‌شه
    description: توضیح کوتاه
    ---

`dir: auto` یعنی هر پاراگراف و تیتر و لیست جهت خودش رو از زبان متنش می‌گیره. کد همیشه چپ‌به‌راست می‌مونه. صفحه‌ی نوشتن همه‌ی این‌ها رو خودش می‌سازه.

## انتشار مستقیم از صفحه‌ی نوشتن

آخر `/editor.html` بخش **Publish to GitHub** هست. توکن گیت‌هاب رو بذار و Publish رو بزن؛ پست و `posts/posts.json` توی **یک commit** روی `main` می‌رن، workflow آروان خودش شروع می‌شه و وضعیتش (queued، in progress، success) همون‌جا نمایش داده می‌شه.

توکن: fine-grained، فقط برای همین ریپو، **Contents: Read and write**. اگه می‌خوای وضعیت دیپلوی هم نمایش داده بشه، **Actions: Read** هم بده (اختیاریه).

- توکن فقط به `api.github.com` فرستاده می‌شه و هیچ‌جای دیگه نمی‌ره.
- پیش‌فرض فقط تا بستن تب توی مرورگر می‌مونه؛ با تیک Remember روی همون دستگاه می‌مونه. با Forget token پاک می‌شه.
- اگه همون نام فایل قبلاً وجود داشته باشه، پست آپدیت می‌شه نه تکراری.
- نام فایل باید انگلیسی باشه (حروف، عدد و خط تیره).

## منبع پست‌ها: گیت‌هاب یا لوکال

توی `config.js` (پیش‌فرض الان `local` ـه، چون سایت با workflow روی آروان آپلود می‌شه و از خود آروان می‌خونه):

    source: "github"    # پست‌ها از ریپوی گیت‌هاب خونده می‌شه
    source: "local"     # پست‌ها از پوشه‌ی posts/ خود سایت

- **github**: فایل `.md` رو توی ریپو push کن و چند دقیقه بعد (کش گیت‌هاب حدود ۵ دقیقه‌ست) روی سایت هست، بدون دیپلوی. اگه گیت‌هاب در دسترس نبود (فیلتر، کندی، قطعی) خودکار از نسخه‌ی خود سایت می‌خونه. ریپو باید public باشه.
- **local**: فقط از خود سایت. بعد از هر تغییر باید دیپلوی بشه (پایین، دیپلوی خودکار).

توی حالت github، لینک فایل و عکس نسبی (`files/x.zip`) هم از گیت‌هاب سرو می‌شه.

## دیپلوی خودکار روی آروان‌کلود

فایل `.github/workflows/deploy-arvan.yml` با هر push روی `main` کل سایت رو توی یه باکت Object Storage آروان (سازگار با S3) آپلود می‌کنه.

یک‌بار تنظیم:

1. توی پنل آروان یه باکت بساز، **Static website hosting** رو روشنش کن (index document: `index.html`) و باکت رو public بذار. بعد دامنه‌ی `blog.ebad84.ir` رو با CDN آروان یا CNAME به آدرس وب‌سایت باکت وصل کن.
2. توی آروان یه Access Key برای Object Storage بساز (جدا از API Key معمولیه).
3. توی گیت‌هاب: ریپو، Settings، Secrets and variables، Actions:
   - Secrets: `ARVAN_ACCESS_KEY` و `ARVAN_SECRET_KEY`
   - Variables: `ARVAN_BUCKET` (اسم باکت) و `ARVAN_S3_ENDPOINT` (آدرس S3 همون ریجنی که باکت رو توش ساختی، از پنل آروان کپی کن؛ مثلاً `https://s3.ir-thr-at1.arvanstorage.ir`)
4. یه push بزن یا از تب Actions بزن Run workflow.

اگه CDN آروان جلوی سایته و بعد از دیپلوی نسخه‌ی قدیمی رو نشون می‌ده، توی پنل CDN کش رو پاک کن (Purge).

## تنظیمات

اسم سایت و فوتر هم توی `config.js` هست. تم: `style.css` (متغیرهای بالای فایل).

## فایل‌ها

    index.html  app.js      صفحه‌ی بلاگ و روتر
    editor.html editor.js   صفحه‌ی نوشتن
    render.js               تبدیل md به HTML (مشترک)
    ui.js                   تم دارک/لایت و دکمه‌ی Copy
    style.css  config.js  posts/  vendor/  fonts/

`vendor/` شامل marked و DOMPurify و `fonts/` شامل JetBrains Mono و Vazirmatn هست؛ هیچ چیزی از اینترنت لود نمی‌شه.
