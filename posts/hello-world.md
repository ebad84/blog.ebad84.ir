This blog reads `.md` files straight from a GitHub repo. Push a file, and it shows up here.

## What works

- **Bold**, *italic*, `inline code` and [links](https://github.com/ebad84)
- Lists, tables and quotes
- Code blocks with a copy button

> Write once in Markdown, render anywhere.

| Field | Meaning |
|-------|---------|
| title | post title |
| date  | YYYY-MM-DD, used for sorting |
| tags  | `[a, b]` or a dash list |
| dir   | `auto` (default), `rtl` or `ltr` |
| draft | `true` hides the post |
